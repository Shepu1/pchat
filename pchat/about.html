Create a room. Own the data.
A private chat app where your conversations live in your own Google Drive — not in someone's database, not on our servers.

💬 What it is

Pchat turns a single link into a full chat room. You make a room, get a link, and send it to whoever you want. They open it, pick a nickname, and you're talking — no signup, no email, no password, no user list, no advertising network.

Here's the part that matters: the room belongs to you. If you create it, the messages are written to a Google Sheet inside your Google Drive. We never see them. We don't even run a server for your chat — we host the web page and nothing else. If the app disappeared tomorrow, your conversations would still be sitting in your own Drive, readable in a spreadsheet.

Quick rooms are even lighter: there is no server at all. Your messages travel directly between the people in the room, and the room is gone the moment everyone leaves.

🌟 Why it's built this way

Six decisions that shape everything else.

🔧 How it works

You create a room. Pchat sets up a Google Sheet in your Drive and gives you a private link. The link carries a secret that never travels to any server — it lives in the part of the URL browsers don't send. That secret is what makes the relay channel unguessable and what lets the app read back any previously encrypted history.

You share the link. Anyone who opens it and picks a name is in. Nothing else is needed.

You talk. Messages appear instantly on everyone's screen. They travel over two independent routes at once — a direct peer-to-peer connection and a cloud relay. If a network blocks one, the other still delivers. Nothing is lost because a router said no.

For a room with a passphrase, each message is encrypted on the sending device before it goes anywhere. The key never leaves the phone or laptop, so the relay only ever sees ciphertext. Without a passphrase, a room is private but not secret — that choice stays with the owner.

🤝 Straight answers

  • Anyone with the link is in the room. That is the design. Rotate the link if that stops being true — the old one stops working immediately.
  • A room without a passphrase is not encrypted. It is private, not secret. The passphrase is what makes it secret, and a passphrase cannot be recovered later — keep it safe.
  • In a saved room the owner can read the messages. It is their Drive. If you need a room where even the owner cannot read you, set a passphrase — the key is derived on your device and never sent.
  • Email sign-in is a nickname, not an account. It tells the room who you are; it does not verify it. Use Google sign-in for a real identity.
  • Google Sheets has usage limits. Pchat is made for small private rooms — a family, a team, a few friends. It is not built to run a public channel with thousands of people.
  • Calls need a direct path. Where a network blocks peer-to-peer traffic, messages still arrive over the relay, but the call may not connect.

🧱 Built on

Plain HTML, CSS and JavaScript — no build step, no framework, no bundler. Open the file and it runs. The whole app is static files that any host can serve.

Web Crypto for encryption, WebRTC for calls, Google Sheets and Apps Script for the backend, and a public relay for instant cross-device delivery. The service worker exists only for notifications — it deliberately never caches, so you always get the current version of the app.
